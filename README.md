# cad-cam-utlis

Vibecoded iterations to translate line curves to real curves and convert connected segments to polylines. 

## Intallation

    git clone https://github.com/thiagoritcher/cad-cam-utils.git

    cd cad-cam-utlis
    python3 -m venv .venv
    source .venv/bin/activate
    pip install ezdxf numpy
